Week 1 Mini Project: SEO Audit
Website: The Body Shop India

Project Type: Search Engine Optimization (SEO) Audit
Website: https://www.thebodyshop.in/
Week: 1

Project Overview

This project evaluates the on-page SEO and performance of The Body Shop India's website. The objective is to identify opportunities to improve search engine visibility, user experience, and website performance.

Audit Objectives
Review title tags and meta descriptions.
Evaluate heading hierarchy (H1, H2, H3).
Check image alt attributes.
Examine URL structure.
Test page speed and performance.
Identify three competitors.
Prepare actionable SEO recommendations.
Tools
Google PageSpeed Insights
Google Search
Browser inspection tools
Manual on-page SEO checklist
Project Files
README.md — Project introduction and overview.
seo-audit-report.md — On-page SEO audit.
page-speed.md — Performance testing and recommendations.
competitor-analysis.md — Competitor comparison.
Expected Outcome

A structured SEO audit report with evidence-based findings, recommended improvements, and priorities for implementation.

Important Note

Page-specific observations and performance scores should be recorded after testing the live website. Recommendations should be updated based on the results.
